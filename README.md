# The Night Manager · NINA plugin downloads

The Night Manager connects [NINA](https://nighttime-imaging.eu/) to your phone: live status, alerts, sub grading,
morning reports and remote control for your observatory, on iPhone and Android.

**This repository only holds the plugin downloads.** Get the newest from
[Releases](https://github.com/phillippeaichinger-cyber/the-night-manager/releases/latest):

| NINA 3.3 nightly | [NightManager-NINA3.3.zip](https://github.com/phillippeaichinger-cyber/the-night-manager/releases/latest/download/NightManager-NINA3.3.zip) |

## Install

1. Close NINA (all instances).
2. Paste `%LOCALAPPDATA%\NINA\Plugins\3.0.0` into File Explorer's address bar.
3. Unzip the download there, so you get a folder called `The Night Manager`. If Windows blocked the zip,
   right-click it → Properties → Unblock first.
4. Start NINA and open Options → Plugins → The Night Manager to pair it with the app.
